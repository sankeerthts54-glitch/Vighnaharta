## 📜 How to Play
**Goal:** Defend the sacred Pandal from the negative energies (Vighnas) during the Ganeshotsav festival! Do not let your Devotion drop to zero.

**Controls:**
- **Select a Tower:** Tap or click a card from the Bottom Deck (e.g., Diya, Ghanta, Trishul).
- **Place Tower:** Tap or click on the grid (grass areas) to spend Modaks and place the tower.
- **Upgrade/Sell:** Tap an existing tower on the board to open the floating menu.
- **Start Wave:** Click the "START" button to send in the next wave of Vighnas.
- **Mushak Charge:** In emergencies, spend 150 Modaks to call Lord Ganesha's Mushak to run down the path and clear enemies.

**Game Mechanics:**
- **Modaks:** Your currency. Earned by purifying Vighnas. Used to build and upgrade towers.
- **Devotion:** Your health. If it drops to 0, the Pandal is overrun.
- **Towers:** 
  - 🪔 *Diya*: Applies stacking Burn damage over time.
  - 🔔 *Ghanta*: Deals area damage and slows enemies.
  - 🔱 *Trishul*: High damage, high armor-piercing projectile.
  - 🌀 *Chakra*: Rapid area-of-effect damage.
  - 🌸 *Lotus*: Weak damage, but restores Devotion on hits.

## 🛠️ Tools Used
- **Engine:** 100% Vanilla HTML5 Canvas and JavaScript. No external game engines.
- **Styling:** CSS3 with dynamic responsive media queries for Mobile and Desktop support.
- **Audio:** Synthesized completely from scratch using the Web Audio API (Oscillators and Gain nodes).
- **Assets:** Emojis and programmatic rendering (zero external image dependencies).
